# 🧮 CalculatorApp

A calculator web application built using **ASP.NET Core MVC, C#, SQL Server, and Entity Framework Core**.

The application performs basic arithmetic operations and stores calculation history in a SQL Server database.

## 🚀 Features

* Addition, subtraction, multiplication, and division
* Division-by-zero validation
* Calculation history
* Search calculations
* Filter by operation
* Pagination
* Edit calculations
* Delete calculations
* Clear calculation history
* SQL Server database integration
* Entity Framework Core migrations

## 🛠️ Technologies Used

* C#
* ASP.NET Core MVC
* Entity Framework Core
* Microsoft SQL Server
* Razor Views
* HTML
* CSS
* JavaScript
* Bootstrap
* Visual Studio

## 🗄️ Database

The application uses **Microsoft SQL Server** with **Entity Framework Core**.

Calculation records are stored in the database and retrieved through the Entity Framework Core `DbContext`.

## ▶️ How to Run

1. Clone the repository.
2. Open the solution in **Visual Studio**.
3. Update the SQL Server connection string in `appsettings.json`.
4. Open **Package Manager Console**.
5. Run:

```powershell
Update-Database
```

6. Press **F5** or click **Run** in Visual Studio.
7. Open the Calculator page in the browser.
